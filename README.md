# SinatraMemo

## 概要
Sinatraを用いたメモアプリです。  
メモの作成、編集、削除が可能です。データはJSONファイルに保存されます。

## 動作環境
* Ruby 3.4.2
* Sinatra 4.1.1
* Bundler
* JSON

## セットアップ手順

### 1. `develop`ブランチのリポジトリをクローンします。
```sh
git clone https://github.com/LxInoue/SinatraMemo.git
```

### 2. アプリケーションのディレクトリに移動します。
```sh
cd SinatraMemo
```

### 3. 必要なGemのインストールします。
```sh
bundle install
```

### 4. アプリケーションの起動します。
```sh
bundle exec ruby app.rb
```

### 4. ブラウザで以下のURLを開きます：
```
http://localhost:4567
```
